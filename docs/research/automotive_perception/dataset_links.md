# Dataset Links

## Lane / road-scene datasets
- CULane - https://xingangpan.github.io/projects/CULane.html
- CurveLanes - https://github.com/SoulmateB/CurveLanes
- BDD100K - https://github.com/bdd100k/bdd100k
- OpenLane - https://github.com/OpenDriveLab/OpenLane
- OpenLane-V2 - https://github.com/OpenDriveLab/OpenLane-V2
- ApolloScape - https://github.com/ApolloScapeAuto/dataset-api
- TuSimple - https://github.com/TuSimple/tusimple-benchmark
- IDD - https://idd.insaan.iiit.ac.in/

## German / traffic datasets
- GTSDB / GTSRB - https://benchmark.ini.rub.de/
- highD - https://www.highd-dataset.com/
- inD - https://www.ind-dataset.com/

## Recommended minimum lane download set
CULane + CurveLanes + BDD100K + OpenLane/OpenLane-V2 + IDD.
Do not download all of them blindly; normalize annotations and assign each dataset a role first.
